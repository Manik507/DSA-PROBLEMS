</span><strong style="font-size: 18px;">Output: </strong><span style="font-size: 18px;">[[1, 4, 7], [2, 5, 8], [3, 6, 9]]
</span><strong style="font-size: 18px;">Explanation: </strong><span style="font-size: 18px;">Swapping mat[0][1] with mat[1][0], mat[0][2] with mat[2][0] and mat[1][2] with mat[2][1].<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/705223/Web/Other/blobid0_1787546826.webp" height="100"><br></span></span></pre>

</span><strong style="font-size: 18px;">Output: </strong><span style="font-size: 18px;">[[2, 10, 10, 6], [7, 1, 4, 9], [3, 5, 7, 1], [1, 1, 6, 8]]
